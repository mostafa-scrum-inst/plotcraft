# F3 — Floor plans: generate, edit, approve; interior questions (Q18–Q19): feature plan

Owner: Tech Lead. Shared decisions: `architecture.md` (A-n).

## Stories covered
F3-S1 Get an automatic plan per floor, F3-S2 Edit the plan, F3-S3 Approve each floor, F3-S4 Choose the interior. Completes R5 end to end (observable result on returning to stage 3) and the F1-S3 R5 criterion.

## Technical approach
- **Generator** (A-8): core block + cells + exhaustive column partitions (full-span or square-ish columns) + assignment search, deterministic. The spike `spikes/layout-spike.mjs` already produces valid layouts for both sample levels, a maximum level (8 rooms + lift), corner/wide/no-stair cases and the CTO's low-fill case, and its seeded sweep fails on 1.5 % of validated programmes at 85 % fill or less; T1 ports it into `PC.layout` and proves it with tests **before** any editor code exists (CTO note).
- **One validity rule** (A-7): a plan belongs to a level only while its stored signature equals the current one. `PC.plans.sync(state)` runs on entering stage 3 and regenerates exactly the stale or missing levels; untouched levels keep edits and approval.
- **Plan view**: frame L, street at the bottom, shared `View2D`. Drawn for reference: plot outline, setback zone, footprint; inside the footprint: hall fill, rooms (2D tint per type, name + area label), stair and lift blocks.
- **Editing** works on frame P rectangles through pure operations in `PC.plans` (`moveRoom`, `resizeRoom` with clamp to the footprint, 1.5 m minimum, and `snapEdge`: neighbouring room/core/footprint edge within 0.3 m first, otherwise the grid of 0.5 m or 1 ft expressed in metres; A-15); the canvas controller only translates gestures. Overlap is allowed during the gesture and evaluated on release with `PC.layout.overlaps`.
- **Approval** is a flag on the plan; any edit clears it. Stage 3 is valid when all plan levels are approved.
- **Stage 4** asks Q18/Q19 (appearance class, plain `commit`) and has the single "Build 3D model" action.
- The Designer supplies all 3D look tables in T3 so F4 can be built against final data shapes.
